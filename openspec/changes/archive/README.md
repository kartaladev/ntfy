# Archived changes

The four `2026-09-14-notify-*` changes were designed and archived in
[hmntsk](https://github.com/kartaladev/hmntsk), where this library was built as
`notify/`, before it moved here. They are copied unchanged from hmntsk commit
`32e7763297a4ac0107c0702da5a5b497c9029083` as design history.

Read them with that in mind: they use hmntsk's paths (`notify/...`), the
package name `notify`, and the storage and wire names that were renamed to
`ntfy` when the library moved (see `spin-out-from-hmntsk`). They also refer to
hmntsk's task engine, which ntfy does not depend on.

Changes archived after the move are this repository's own.

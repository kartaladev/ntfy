# Harden Hub Streams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An open realtime stream never outlives its instance's ability to deliver signals to it, tells its client when to come back, and counts against a bounded total per instance.

**Architecture:** `Subscription` gains a `done` channel that `Hub.endRun` closes for every open subscription when a run ends; both transports select on it and end the stream. `Subscribe` decides and inserts in one critical section under `h.mu`, using a `receiving` flag written under the same lock, so a run ending mid-subscribe cannot hand out an orphan. A stream counter under the same lock enforces a per-instance cap alongside the existing per-recipient one, and the SSE transport writes a jittered `retry:` field when a stream opens.

**Tech Stack:** Go 1.26, standard library only in the core module (`net/http`, `sync`, `sync/atomic`, `math/rand/v2`); `github.com/coder/websocket` in the `ntfy/websocket` module; `stretchr/testify` and `go.uber.org/mock` for tests; `go.uber.org/goleak` in both `TestMain`s.

**Spec:** `openspec/changes/harden-hub-streams/` — read `proposal.md` (why), `design.md` (D1–D5, the decisions this plan implements), and `specs/notification-realtime/spec.md` (the requirements and scenarios). `tasks.md` is the checklist this plan expands.

- [ ] **Step 4: Close subscriptions when a run ends, and stop accepting in the same breath**

In `hub.go`, replace `markReady` and `endRun` (`:160-190`) with:

```go
// markReady records that a run's broadcaster has subscribed. It changes nothing
// for a run that is not the current one, such as one that has ended, or when the
// current run is already receiving, so a late or repeated ready is harmless.
func (h *Hub) markReady(run *hubRun) {
	h.runMu.Lock()
	defer h.runMu.Unlock()

	if h.current != run || h.running.Load() {
		return
	}

	h.running.Store(true)

	h.mu.Lock()
	h.receiving = true
	h.mu.Unlock()

	close(h.readyCh)
}

// endRun returns the hub to idle. A Ready channel the run closed is replaced by
// an open one for the next run; one it never closed is kept, so that a host
// still waiting on it is woken by whichever run subscribes next.
func (h *Hub) endRun() {
	h.runMu.Lock()
	defer h.runMu.Unlock()

	h.current = nil
	h.running.Store(false)
	h.closeSubscriptions()

	select {
	case <-h.readyCh:
		h.readyCh = make(chan struct{})
	default:
	}
}

// closeSubscriptions stops accepting streams and closes every open one, so that
// no stream outlives the run that fed it. A later run starts with none.
func (h *Hub) closeSubscriptions() {
	h.mu.Lock()
	defer h.mu.Unlock()

	h.receiving = false

	for _, held := range h.subscriptions {
		for subscription := range held {
			subscription.closeLocked()
		}
	}

	h.subscriptions = make(map[string]map[*Subscription]struct{})
}
```

Lock order stays `runMu` → `mu`, which is the order `endRun` and `markReady` both take. Nothing takes them the other way.

- [ ] **Step 5: Decide and insert under one lock in Subscribe**

In `hub.go`, replace `Subscribe` (`:243-272`) with:

```go
// Subscribe opens a subscription to a recipient's signals.
//
// It does not authorize: a transport asks its [SubscriptionAuthorizer] first.
// A hub that is not receiving signals refuses with an error matching
// [ErrUnavailable], and a recipient already holding the maximum number of
// subscriptions on this instance is refused with one matching
// [ErrTooManyStreams]. Every subscription must be closed, and a subscription is
// closed for the caller when the hub's run ends.
func (h *Hub) Subscribe(recipient string) (*Subscription, error) {
	h.mu.Lock()
	defer h.mu.Unlock()

	if !h.receiving {
		return nil, fmt.Errorf("%w: the hub is not receiving signals", ErrUnavailable)
	}

	held := h.subscriptions[recipient]
	if len(held) >= h.maxStreams {
		return nil, fmt.Errorf("%w: %d streams are already open for this recipient", ErrTooManyStreams, h.maxStreams)
	}

	if held == nil {
		held = make(map[*Subscription]struct{})
		h.subscriptions[recipient] = held
	}

	subscription := &Subscription{
		hub:       h,
		recipient: recipient,
		ready:     make(chan struct{}, 1),
		done:      make(chan struct{}),
	}
	held[subscription] = struct{}{}

	return subscription, nil
}
```

- [ ] **Step 6: Give Subscription its done channel and a lock-held close**

In `hub.go`, replace the `Subscription` struct and `Close` (`:274-289` and `:324-338`) with:

```go
// Subscription is one open stream's view of a recipient's signals.
//
// It holds at most one pending signal: signals arriving before the stream takes
// one replace it. A signal carries no content, so the latest says everything
// the ones it replaced did, and a client that stops reading costs no memory and
// never slows a publisher.
type Subscription struct {
	hub       *Hub
	recipient string
	ready     chan struct{}
	done      chan struct{}
	closeOnce sync.Once

	mu      sync.Mutex
	pending Signal
	has     bool
}
```

and

```go
// Done is closed when the subscription ends, whether its stream closed it or
// its instance stopped receiving signals. A transport selects on it alongside
// [Subscription.Ready] and ends the stream when it closes; a transport that
// ignores it is left holding a stream no signal will ever reach.
func (s *Subscription) Done() <-chan struct{} { return s.done }

// Close ends the subscription and frees its slot in the recipient's cap. It is
// safe to call more than once.
func (s *Subscription) Close() {
	s.hub.mu.Lock()
	defer s.hub.mu.Unlock()

	s.closeLocked()
}

// closeLocked ends the subscription exactly once. The caller holds the hub's
// lock, so that a stop can close every subscription in one critical section.
func (s *Subscription) closeLocked() {
	s.closeOnce.Do(func() {
		close(s.done)

		held := s.hub.subscriptions[s.recipient]
		if _, open := held[s]; !open {
			return
		}

		delete(held, s)

		if len(held) == 0 {
			delete(s.hub.subscriptions, s.recipient)
		}
	})
}
```

`http.Server.Shutdown` ends neither transport on its own. A WebSocket is a

## Notes for the implementer

- **Lock order is `runMu` → `mu`, always.** `endRun` and `markReady` hold `runMu` and take `mu`; `Subscribe` and `Subscription.Close` take only `mu`. Nothing may take `runMu` while holding `mu`.
- **Do not close `Subscription.ready` to signal closure.** `offer` does a non-blocking send on it while holding no lock that orders against a close, so closing it panics with a send on a closed channel the moment a signal is delivered during a stop. That is why `done` is a separate channel (`design.md` D1).
- **`closeLocked` is called while ranging over the maps it deletes from.** Deleting during a range is defined behaviour in Go; entries already removed are simply not produced.
- **Test timings.** `hubWait` (2s, root) and `testWait` (WebSocket module) exist to turn a hang into a failure, not to wait for anything expected. No new `time.Sleep` appears anywhere in this plan; every wait is a channel or an existing helper.
- **`TestHubSubscribeDuringStop` is the one probabilistic test here.** It loops 100 times precisely because the window it covers is a race; the race detector widens it. Its assertion is an invariant that holds deterministically once the fix is in.
